## Overview

BTC War is a browser-first crypto visualization tool centered on Bitcoin market activity. It brings together live BTC pricing, BTC/USDT order flow, depth, liquidity, and executed trades in one interface so the market can be scanned quickly and explored visually.

Built with WebGL and Three.js, the project presents market movement as an interactive 3D battlefield. It is intended for users who prefer a more visual way to follow real-time trading pressure, volume shifts, and market structure directly in the browser.
